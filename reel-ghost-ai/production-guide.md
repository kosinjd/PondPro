# 🛠️ คู่มือประกอบคลิป + ลง Facebook

## ขั้นตอนประกอบ (เรียงตามนี้)

### 1) เจนภาพ/วิดีโอใน Hyper Frame
- เปิด `hyperframe-prompts.md` ก๊อปพรอมต์ทีละ scene (1–6)
- ตั้ง 9:16 / 1080×1920 / 30fps ทุก scene
- ใช้ seed เดิมกับ scene ที่มีตัวละคร/ห้องเดิม (1, 3, 4, 6) เพื่อความต่อเนื่อง
- เซฟคลิปเป็น `assets/scene1.mp4` … `assets/scene6.mp4`

### 2) ทำเสียงบรรยาย (VO)
- เอา `voiceover.txt` เข้า TTS เสียงไทย เช่น Botnoi, BotNoi Voice, iApp, ElevenLabs (รองรับไทย), หรือ Google TTS
- เลือกเสียง **ผู้ชาย ทุ้มต่ำ** ตั้งความเร็ว ~0.9x
- ถ้าอัดเองได้ยิ่งดี (อารมณ์จะถึงกว่า) โดยเฉพาะบรรทัดสุดท้ายให้ "กระซิบ"
- เซฟเป็น `assets/vo.mp3`

### 3) ประกอบในตัวตัดต่อ
ใช้ CapCut / Premiere / DaVinci ก็ได้ เรียง scene 1→6 ให้ตรงไทม์โค้ดใน `script-th.md`
- ลาก `assets/vo.mp3` ลง track เสียงพูด
- ลาก `captions.srt` ใส่เป็นซับไตเติล (CapCut: Import captions)
- **ฟอนต์ซับ:** ฟอนต์ไทยหนาๆ อ่านง่าย เช่น Anuphan / Noto Sans Thai Bold สีขาว ขอบดำ วางกลางล่าง เผื่อขอบ Reels

### 4) ข้อความไทยบนจอ (ถ้า Hyper Frame เรนเดอร์ไทยเพี้ยน)
- เจน scene 2, 4, 5, 6 เป็น "จอเปล่า/จอเบลอ" แล้วพิมพ์ทับในตัวตัดต่อ
- ใช้สไตล์ฟอนต์ monospace สำหรับโค้ด (scene 2) เช่น `// มีคนยืนอยู่ข้างหลังคุณ`

### 5) เพลง + เสียงประกอบ (สำคัญมากกับสายผี)
- **0:00–0:21** เพลงแอมเบียนต์มืดๆ ตึงๆ (dark ambient / horror drone) เบาๆ คลอ
- **0:16** ใส่ string stab / เสียงวาบ ตอน AI ตอบ "ผมเห็นเธอ"
- **0:21 เป็นต้นไป** เปลี่ยนเป็นเปียโนเศร้าอ่อนๆ พลิกอารมณ์เป็นซึ้ง
- **0:32** เงียบ 1 จังหวะก่อนจบ ให้คนอิน
- หาเพลงไม่ติดลิขสิทธิ์จาก Facebook Sound Collection / YouTube Audio Library (คีย์เวิร์ด: horror ambient, sad piano)

### 6) เอ็กซ์พอร์ต
- 1080×1920, H.264, 30fps, บิตเรต ~10–12 Mbps, เสียง AAC 256kbps
- เช็กว่าซับไม่โดน UI ของ Reels บัง (เว้นขอบล่าง ~250px, ขอบขวา ~120px)

### แฮชแท็กแนะนำ
`#เรื่องผี #ผีจริง #หลอน #AI #ปัญญาประดิษฐ์ #เรื่องเล่ากลางดึก #สายมู #FacebookReels #คลิปสั้น #ซึ้ง #น้ำตาจะไหล`

### เคล็ดยอดวิว Reels
- **3 วิแรกคือทุกอย่าง** — ฮุก "ตี 3 ผมอยู่คนเดียว... แต่ AI ไม่คิดงั้น" ต้องเด้งทันที
- โพสต์ช่วง **2–4 ทุ่ม** (คนชอบดูเรื่องผีตอนกลางคืน)
- ปักคอมเมนต์แรกถามคนดู → ดัน engagement
- ทำเป็นซีรีส์ "เรื่องเล่าจาก AI" ตอนต่อไปได้ ถ้าตอนนี้ปัง
