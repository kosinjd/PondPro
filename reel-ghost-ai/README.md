# 🎬 รีลผีกับ AI — "ผู้ใช้คนที่สอง"

ชุดงานผลิตคลิป **Reels แนวตั้งสำหรับ Facebook** เรื่องผีกับ AI พร้อมบทพากย์
ออกแบบมาเพื่อป้อนเข้า **Hyper Frame** (AI video generator) แล้วประกอบเป็นคลิปสำเร็จ

> Workflow: **Claude Code เขียนบท + สตอรีบอร์ด + พรอมต์ → Hyper Frame เจนภาพ/วิดีโอแต่ละ scene → ประกอบ + ใส่เสียง → ลง Facebook Reels**

---

## 📐 สเปกคลิป

| รายการ | ค่า |
|---|---|
| สัดส่วน | 9:16 แนวตั้ง |
| ความละเอียด | 1080 × 1920 px |
| ความยาว | ~30 วินาที |
| เฟรมเรต | 30 fps |
| แพลตฟอร์ม | Facebook Reels (ใช้กับ IG/TikTok/YouTube Shorts ได้) |
| โทน | ผีหลอน + ทวิสต์ซึ้ง |
| ภาษา | บรรยายไทย + ซับไตเติลไทย |

## 📖 เรื่องย่อ

ตี 3 โปรแกรมเมอร์เขียนโค้ดอยู่คนเดียว แชท AI เริ่มแทรกข้อความเตือนว่า
"มีคนยืนอยู่ข้างหลังคุณ" เขาคิดว่าเป็นบั๊ก จนเปิด log เจอผู้ใช้คนที่สอง
ที่เชื่อมต่อมา 412 วัน — ชื่อ `nong_fah` น้องสาวที่จากไปเมื่อปีก่อน
บรรทัดสุดท้าย AI พิมพ์ชื่อเล่นที่มีแค่เธอเท่านั้นที่รู้

## 🗂️ ไฟล์ในชุดงาน

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `script-th.md` | บทพากย์เต็ม + ไทม์โค้ดทุก scene |
| `storyboard.md` | สตอรีบอร์ดละเอียด (ภาพ/บรรยาย/ซับ/เสียงประกอบ) |
| `hyperframe-prompts.md` | พรอมต์ภาษาอังกฤษต่อ scene สำหรับ Hyper Frame |
| `scenes.json` | ข้อมูลโครงสร้างทุก scene (import เข้าทูลได้) |
| `voiceover.txt` | บทบรรยายล้วน สำหรับเข้า TTS / อัดเสียง |
| `captions.srt` | ไฟล์ซับไตเติล (ลากใส่ตัวตัดต่อได้เลย) |
| `production-guide.md` | คู่มือประกอบคลิป + เพลง + แคปชั่นโพสต์ + แฮชแท็ก |
| `preview.html` | พรีวิวสตอรีบอร์ดแบบ 9:16 เปิดดูในเบราว์เซอร์ |

## ▶️ เริ่มยังไง

1. เปิด `preview.html` ในเบราว์เซอร์เพื่อเห็นภาพรวมคลิป
2. ก๊อปพรอมต์จาก `hyperframe-prompts.md` ไปเจนภาพ/วิดีโอใน Hyper Frame ทีละ scene
3. เอาเสียงจาก `voiceover.txt` ไปเข้า TTS เสียงไทย (หรืออัดเอง)
4. ประกอบตาม `production-guide.md` แล้วลาก `captions.srt` ใส่ซับ
5. เอ็กซ์พอร์ต 1080×1920 → อัปโหลด Facebook Reels
